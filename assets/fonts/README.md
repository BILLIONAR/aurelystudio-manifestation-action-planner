# Self-hosted fonts

The Latin WOFF2 files in this folder are from the locally installed `@fontsource` packages in the AurelyStudio ADHD Budget Planner reference project. The matching original SIL Open Font License notices are in `licenses/`.

Included families: Cormorant Garamond, Nunito Sans, Inter, Lora, Atkinson Hyperlegible, Kalam, Caveat, Patrick Hand, Dancing Script, and Sacramento. All include 400 normal. Cormorant Garamond, Nunito Sans, Inter, Lora, and Atkinson Hyperlegible also include available 600 and 700 normal weights. Atkinson Hyperlegible has 400 and 700 only in the source package.

Use local `@font-face` URLs with `font-display: swap`; preserve the original license files in any customer package containing these fonts.
