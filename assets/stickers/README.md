# Manifestation & Action Planner sticker pack

Twelve original SVG stickers for the Vision Board and manifestation workflow. Each file is a transparent, square vector (`viewBox="0 0 128 128"`) with a warm paper rosette behind its line art, designed to stay legible over photographs. The palette follows the app's ivory, sage, terracotta, and muted gold colors.
